# Control Centre

Personal, native Android control panel for Mani's Samsung (One UI 9 / Android 17).

Three separate pages: Everyday, Tools, Device. Open a chosen page with one gesture; no mandatory Quick Settings tile or launcher hop.

## Live implementation

See [PROGRESS.md](PROGRESS.md) and the [commit history](../../commits/main). Each completed implementation stage is committed to `main`. Intermediate stages explicitly marked `[skip ci]` are source checkpoints, not installable releases.

The experimental top-right accessibility strip is **not yet verified on the phone**. Direct side gestures and exported page shortcuts are independent alternatives. Samsung's original notification shade is not disabled.

No APK or successful build exists at the foundation checkpoint. Tests must be executed before their results are claimed.
